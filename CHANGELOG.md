# Changelog

## 2026-06-03: Dinsical 1.026

- Fixed line height (120%) for variable TTF font 

## 2026-05-13: Dinsical 1.025

- Improved sizing and alignment for diacritical marks
- Add arrows and other symbols
- Single variable WOFF2 font with two axies is replaced with two fonts with one axies - `Dinsical[wght].woff2` and italic `Dinsical-Italic[wght].woff2` for better Safari compatibility. The TTF version (`Dinsical[slnt,wght].ttf`) remains as is with 2 axis.

## 2026-05-05: Dinsical 1.020 and Monsical 1.002: 

- Vietnamese language support

## 2026-04-22: Dinsical 1.019 and Monsical 1.001

- Initial public release
